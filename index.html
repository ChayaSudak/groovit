How it works

  1. 1Mid-run, a question appears: jump for one answer, squat for the other.
  2. 2Right answers earn coins.
  3. 3Follow-up questions come back tailored to each child.

Worlds to explore

Different worlds, one running adventure.

Each world folds a different kind of learning into the run—and teachers choose which ones a class plays.

Social emotional world

Practice how to treat each other

Reflection moments and kindness rounds are part of the gameplay, not a separate worksheet.

Math world

Number gates adapt to each child, so everyone is working at the right level.
